# 学生测试程序

一个基于 Python 的命令行随机测验程序：掷 3 个骰子生成“学习币值”，按分值自动抽取 A/B 卷，学生逐题作答后自动判分，并将成绩写入 CSV 成绩单。

## 功能特性

- 🎲 **学习币值**：随机掷 3 个 1~6 点的骰子，总分为 3~18
- 📝 **自动组卷**：币值 3~10 抽 A 卷，11~18 抽 B 卷，每卷 10 道判断题
- ✍️ **交互式答题**：只接受“正确”或“错误”，格式有误会提示重新作答
- 💯 **自动判分**：每题 10 分，满分 100 分，答完展示逐题对错与标准答案
- 📊 **成绩管理**：同名学生更新成绩，新学生追加到成绩单末尾
- 🔒 **编码兼容**：读取成绩单自动兼容 UTF-8 / UTF-8-sig / GBK；输出使用 UTF-8-sig，Excel 双击打开不乱码

## 环境要求

- Python 3.x
- 仅使用标准库（`csv`、`os`、`random`、`sys`），无需安装第三方依赖

## 运行方式

程序内部使用相对于**当前工作目录**的路径（`../data/...`），因此请先进入 `code` 目录再运行：

```bash
cd code
python 测试程序.py
```

Windows 也可以使用 `py 测试程序.py`。

## 使用流程

1. 程序掷 3 个骰子，输出学习币值（例如 12）。
2. 根据币值自动抽取试卷：3~10 抽 A 卷，11~18 抽 B 卷。
3. 输入姓名（自动合并多余空格，全角空格也会被处理）。
4. 逐题作答，每题输入“正确”或“错误”。
5. 程序输出每题的对错、答对/答错题数和总分。
6. 结果写入 `tmp/更新后的成绩单.csv`。

运行示例：

```text
学习币值为: 12
------试卷抽取完毕-------
本卷共有10题，标准答案为: ['错误', '错误', '错误', ...]
------测试开始-------
请输入名字: 张三
学生名字: 张三
第1题: 关键字参数可以和其它类型的参数一起使用，如果一起使用，那么关键字参数必须位于最后面。
请输入第1题的答案(注意输入格式为"正确"或"错误"): 正确
...
------成绩与标准答案------
总题数:10 答对:7 答错:3 得分:70
更新后的成绩单已写入文件: ../tmp/更新后的成绩单.csv
```

## 计分规则

- 每卷共 10 道判断题，每题 10 分，满分 100 分
- 答对得分，答错或未作答计 0 分
- 答案严格匹配“正确” / “错误”

## 数据文件说明

| 文件 | 格式 | 说明 |
| --- | --- | --- |
| `data/成绩.csv` | `姓名,成绩` | 原始成绩单，程序只读不改 |
| `data/试卷/A卷.csv`、`B卷.csv` | 每行一道题，无表头 | 题库内容 |
| `data/试卷答案/A卷答案.csv`、`B卷答案.csv` | `题目,答案`，首行为表头 | 标准答案 |
| `tmp/更新后的成绩单.csv` | `姓名,成绩` | 运行生成的结果文件 |

## 注意事项

- 必须从 `code/` 目录启动程序，否则 `../data/...` 会指向错误位置，导致读不到试卷。
- 更新后的成绩单**不会覆盖**原始数据 `data/成绩.csv`，而是写入 `tmp/`。
- 学习币值超出 3~18 时试卷抽取会失败，程序将退出并提示原因。
- `.venv/`、`tmp/`、`__pycache__/`、`.idea/` 等本地文件已通过 `.gitignore` 排除。
